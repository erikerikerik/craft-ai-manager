## CI round 1 (2026-10-16): the deny job rejected our own licence

Run 38939106453 on `ba803973`: `check (ubuntu-latest)`, `check (windows-latest)` and
`msrv (1.95)` all passed; `deny` failed with one `error[rejected]: failed to satisfy license
requirements` on `path+file:///github/workspace/crates/caim#craft-ai-manager@0.1.0`, whose
expression cargo-deny read out of `LICENSE.md` as `PolyForm-Noncommercial-1.0.0`. advisories, bans
and sources were all ok; the four `warning[duplicate]` lines (miniz_oxide, syn, windows-sys, and
one more) are warnings, which is what the prompt asks for.

This is our failure, not a pre-existing one: the job did not exist before this PR. The fix is a
name-scoped exception, not a wider allow list:

```toml
[[licenses.exceptions]]
name = "craft-ai-manager"
allow = ["PolyForm-Noncommercial-1.0.0"]
```

An exception applies to that one crate, so a third-party dependency under PolyForm Noncommercial
still fails the gate. The allow list is unchanged, which keeps amendment 17 Erik's call.
