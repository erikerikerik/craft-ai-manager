## Known gaps and follow-ups

- **`webpki-roots 1.0.9` is CDLA-Permissive-2.0**, which is not in the licence list the MG-02 prompt allows. Flagged above; Erik decides whether a permissive attribution licence over the Mozilla root list is acceptable. If not, the fix is a vendored root list or the OS trust store.
- No resume and no cancellation mid-download: CAIM-03 puts resume in S2 and MG-05 adds cancellation. A 5 s download on this connection makes that easy to live with for now.
- `/v1/tasks` is unchanged: MG-02 deliberately did not touch the wire contract, so an installed model is not yet offered to PhotoCraft. That needs MG-04 (the `ort` runner) and MG-05 (the staged runner), which is where `store::is_installed` should feed the task list.
- `models install <id>` and `models verify <id>` resolve an id to its only catalog entry; two versions of one id is an error rather than a silent choice (`models::find`). Version choice belongs with CAIM-02.
- No `caim models delete`, and no disk-usage reporting: CAIM-02 and CAIM-05.
- `acknowledged.json` sits in the model's own folder, so deleting the model also forgets the acknowledgment. That is deliberate for M1 - a fresh download re-shows the note - but a shared record may be wanted later.
- The deny list matches words, prefixes and phrases (`gpl`, `lgpl`, `agpl`, `nc`, `openrail`, `research only`, `non commercial`, `noncommercial`). A licence phrased some other way, say "for research purposes only", slips through, which is why the gate is a first filter and the override plus this receipt stay the human step.
- `.gitignore` needed `!docs/models/`: the `models/` rule that keeps weights out also matched `docs/models/`. The weight patterns still bite inside it, so a stray `.onnx` there stays untracked.
- The two mode-0600 tests are `#[cfg(unix)]`, so only the ubuntu CI job can prove them; nothing on this PC can.
- MSRV is still declared (`rust-version = "1.95"`) and untested; CI builds stable. Carried over from MG-01.
- PhotoCraft `agents/FEATURES.md` rows CAIM-03 and CAIM-11 are what MG-02 implements. They stay `todo` for the review to tick, as CAIM-01 did for MG-01.
